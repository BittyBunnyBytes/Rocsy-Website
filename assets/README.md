# Rocsy website assets

`rocsy-service.svg` and the `rocsy-v2-*` icons are the Rocsy app icon
(`BunnyBytes/gateway/static/icons/rocsy-v2.svg` in the Rocsy repository).

The `service-*.svg` files use the studio icon shapes from the Rocsy home page
(`BunnyBytes/gateway/templates/home.html`), drawn in a neutral colour.

`v1/` holds older icon versions kept for history; the page doesn't use them.
