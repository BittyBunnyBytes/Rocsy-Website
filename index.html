Studios

Everything you make, in one place.

Each studio has its own page, presets and job history. They all share the same models library, notifications and GPU queue.

Master Agent

Ask for the result, not the steps.

The Master Agent is a local Hermes agent that drives every studio for you. Describe a short film, a music video or a set of product shots. It plans the work, queues each render, looks at the results and redoes what didn't come out right.

  • Runs on your own LLM through llama.cpp
  • Uses the studios' Agentic modes for videos, images and songs
  • Edits frame-exact cuts, adds soundtracks and captions
  • Asks before it touches anything you've set to "ask first"

How it works

Containers coordinate. Your GPU computes.

1

One gateway

A single password-protected web app. Open it on your PC, or from your phone through an optional Cloudflare tunnel.

2

Studios and the GPU queue

Small services in Docker Compose. They take your requests, line up GPU work and keep your history.

3

Native GPU backends

ComfyUI and llama.cpp run on the host with ROCm, so they get the whole card. A host helper starts, stops and updates them for you.

Your files stay yours

Outputs, uploads, models and datasets are ordinary folders on your disk. Nothing is uploaded unless you set it up.

One models library

Download a model once; every studio that can use it sees it. Add more drives in Settings → Storage.

Safe updates

Backends update only while nothing is running, and you can always roll back to the previous build.

Install

From download to first render.

The installer sets up Docker, the services and, if you want, ComfyUI and the agent. Then you pick models inside Rocsy.

  1. 1
    Download

    Get rocsy-v1.2-installer.tar.gz from the latest release.

  2. 2
    Run the installer

    Choose what to install, where, and your password. It asks before changing anything on your system.

  3. 3
    Add models

    Open Models, see what fits your GPU and download it. Then start creating.

Extract the download and double-click Install Rocsy. A guided setup opens in your browser.

tar -xzf rocsy-*-installer.tar.gz
sh "Rocsy Installer/Install Rocsy.sh"

Same questions in the terminal. Press Enter for the defaults, or add --defaults to skip them.

tar -xzf rocsy-*-installer.tar.gz
sh "Rocsy Installer/Install Rocsy.sh" --terminal

On Windows 10 (2004 or newer) and 11, run Install Rocsy (Windows).cmd. It sets up WSL2 and installs Rocsy inside it. This path is untested; Linux is the supported way.

System

Linux with an AMD GPU that ROCm supports. Arch, Ubuntu, Debian, Fedora, openSUSE and more: the installer uses your package manager.

GPU memory

Developed on a 24 GB RX 7900 XTX. Smaller cards work with smaller models; Models shows what fits.

Disk space

Video models and LoRA datasets are large. Plan on hundreds of GB if you want every studio.

FAQ

Questions

Does it work on NVIDIA?

Rocsy is built and tested for AMD GPUs with ROCm. Some parts may run elsewhere, but NVIDIA isn't supported.

Which AMD cards?

It's developed on an RX 7900 XTX (RDNA3). Other cards that ROCm supports should work. The LLM server can build llama.cpp for your card's GPU target, and Models checks what fits in your VRAM.

Are models included?

No. The installer is a few MB. You download the models you want from inside Rocsy, from Hugging Face or Civitai.

Is anything sent to the cloud?

Generation runs on your GPU. Model downloads, optional web search by the agent, and the optional Cloudflare tunnel use the internet; everything else stays on your machine.

Can I use it from my phone?

Yes. Set up a Cloudflare tunnel on the Connections page and log in from anywhere. Push notifications tell you when a render finishes.

How do I update?

Run a newer installer and choose Update; your settings, history and models are kept. Backends like ComfyUI and llama.cpp update from Models → Manager.
